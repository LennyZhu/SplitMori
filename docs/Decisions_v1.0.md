## 2. 五项新决策的生效细节

- **DEC-P01 → F18**：手动保存是计算快照；保留可选付款人、计算模式、金额、币种、成员稳定 ID、版本/时间，允许无付款人历史；入正式活动需核对成员、补齐商家付款人并保证幂等。
- **DEC-P02 → F19**：默认最终总额已经包含服务费和折扣；进入明细后才单独计算，10% 和手动服务费二选一；必须与实际收据相符。默认费用按原消费权重分配并严格守恒。
- **DEC-P03 → F20**：在临时目录验证备份哈希与内部金额关系、版本兼容及资产完整性，再显示覆盖数量，经明确同意后安全替换；失败仍保留旧数据库。备份不授予 Pro 权益。
- **DEC-P04 → F21**：有效购买证据、已明确无 Pro、暂不可验证是不同状态；unknown 不自动降级，保持已有可信权益证据的合理离线使用，不能信任用户自行编辑的本地解锁标记。明确 Free 且多个活动时仅业务费用编辑受限，历史还款及结算仍工作；活动数量回到 1 后恢复 Free 范围内编辑。
- **DEC-P05 → F22**：更正原费用前显示费用/退款/分摊/还款变化；实付金额不得小于有效退款总额；修改退款责任须用户明确复核；退款冲销更正需留痕；失败回滚。

## 3. 仍需独立处理的发布/视觉事项

- `O01`：首页及主流程低保真验收；`O05`：独立深色主题是否在 1.0 实施（系统深色必须可读）。
- `O06`：香港 Pro 正式价格（讨论中的 HK$28 / HK$38 **不是正式定价**）。
- `O07`：App Store 中文/英文标题、副标题及可用性核验。
- `O08`：独立 Bundle ID、IAP Product ID、隐私政策/支持站点。
- `O11`：分币种金额输入上限/小数位配置，经技术设计验证后冻结常量。

**已关闭**：`O02 O03 O04 O10 O12` 被 F18–F22 覆盖；`O09` 已并入 F18。发布准备事项不意味着核心业务未冻结。

## 4. 变更管理

任何冻结项变更必须创建新的 `DEC-YYYYMMDD-NN` 记录，写明提出人、问题、行为变更、财务/权限/历史数据影响、数据库迁移和新增/更新验收测试；产品负责人确认后才能调整主 PRD。Codex 不得擅自更改金额公式、退款追溯、付费边界。
