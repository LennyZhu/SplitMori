## 3. 第一张未来 Codex 任务单应该长什么样（非立即执行）

- **目标**：只在用户授权时开始 P1：定义纯 TypeScript 财务领域 API，测试分摊/付款/退款/还款/净额与余数；先用模拟的领域对象，不连接 SQLite 或屏幕。
- **输入**：两份 v1.0 文档，注明 F01–F22 已冻结、不得擅自变更。
- **必备输出**：类型/API 设计解释、修改文件清单、失败测试与修复记录、不能实现的边界、手动验收待办。
- **验收方式**：精度、守恒、重复事件幂等、审计事件不可被静默删除、事务边界说明，轻量自动化检查。
- **禁区**：禁止创建 App Store 产品、EAS 证书、真实 Supabase 项目、推送生产数据、操作真实设备/Simulator。
