本版設計重點

1入口清晰

從 S07 活動詳情的「管理成員」進入，不新增主 Tab，也不影響其他導航。

2新增不改舊帳

新增 c、d 後，旅行變成四人活動；原本 a、b 的兩筆費用、付款和餘額完全不變。

3不能誤刪歷史成員

已參與正式費用或還款者不提供危險刪除操作。修改顯示名稱與歷史 ID 必須分開。

4回到快速記錄

增加成員後，可重新將原四人快速分帳按一對一成員映射加入活動。
