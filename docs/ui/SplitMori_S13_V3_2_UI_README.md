## 已凍結／已確認的產品規則
- 不新增帳號、伺服器或雲端同步；S13 接現有 SQLite 完整備份／還原服務。
- 語言：跟隨系統、繁體中文（香港）、English。手動選擇要持久化、全局即時生效，並傳遞到 S09/S11 等頁面。
- 預設幣別只有 HKD、CNY、MOP、TWD、USD、JPY。只影響新分帳，不能修改舊活動幣別或將金額換匯。
- 備份操作先由既有服務完成完整性校驗；匯出檔名／格式／內容及匯入驗證結果由真實服務回傳，不可把高保真的例子寫死。
- 還原是全量覆蓋，不是合併。必須先選檔、驗證、預覽差異及明確二次確認；使用既有安全交易、SHA-256、回滾與中斷恢復能力，不要建立另一套恢復邏輯。
- 還原成功必須在持久化與校驗真正完成後才能顯示；驗證失敗時不得觸碰原資料。
- 不能聲稱未知提交結果是成功或失敗；異常中斷依既有機制查證與恢復。
- SplitMori Pro 購買和恢復購買屬 S12，S13 只能保留清晰非功能入口或待接線狀態，不能模擬成功。
- 隱私、條款和支援 URL 必須是真實配置；未有正式連結時保持不跳轉或明確提示，不能捏造。
- 高保真的版本號及備份項目數量只是排版樣例，實際值需要由 App 配置及本機服務取得。

S13 的工作限於設定頁、本地語言偏好／預設幣別、完整備份匯出、文件選擇／還原預覽／覆蓋確認、錯誤及完成狀態、關於及法律支援入口。不要提前開發 S12 IAP 和 Pro 高級功能。做成一個整體階段，避免過度拆分。
