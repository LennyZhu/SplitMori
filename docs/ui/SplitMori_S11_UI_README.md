## 确定范围

S11 **不做独立设置页**；从 S09 进入结算图预览，可直接「儲存或分享」。Free 仅一种标准黑白模板。已完成未结清与已结清是**状态示例**，不是新增单独业务入口。正式 PNG 按当前 SQLite 账本快照生成，页面不得出现示例中的固定姓名或金额。

## 示例账本，仅用于高保真

活动「旅行」，HKD，日期 2026-11-07，四位成员。
有效费用 1,120.00；有效商家退款 0.00；已登记有效成员还款 0.00；待结算 700.00。
a 应收 700.00；b 应付 420.00；Chris 应付 140.00；d 应付 140.00。
转账建议：b → a 420.00；Chris → a 140.00；d → a 140.00。

`05` 与 `06` 是**不同的账本状态**：已完成未结清仍待结算 700.00；已结清示例假设 b、Chris、d 各自完成全部真实还款（有效还款总额 700.00），待结算为 0.00、各成员当前净额为 0，建议转账为 0 笔。

## 实现原则

- 黑白极简 `#FDFCFB` / `#FFFFFF` / `#282828` / `#E7E5E2`；导出 PNG 是精致收据式白底卡片，**不要使用旧版四块灰色后台报表式模板**。
- 状态分开：活动状态 ≠ 财务结清状态；“已完成”不等于“已结清”。
- 生成、保存、分享都只读，不写入财务事件、不改变活动状态。
- 结算金额全部复用 S09 的现有结算服务，禁止把示例金额硬编码。
- 长姓名、长成员列表和转账列表必须自适应；PNG 不裁切内容。
- 按用户语言使用 zh-HK 或 en；币种符合现有整数最小货币单位格式，JPY 不显示两位小数。
- 保存到相簿成功才反馈“已儲存”；调用系统分享不代表实际发送成功。
