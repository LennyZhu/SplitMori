交互範圍

S09「查看還款記錄」→ 歷史列表 → 詳情 → 二次確認作廢 → 返回並更新 S09。已完成活動也可作廢還款，不必重新開啟。

帳務規則

只追加作廢事件，不刪除或改寫原還款；同一筆最多作廢一次。作廢後從 SQLite 重新計算每人淨額和建議，不能自行改數字。

重要限制

本階段不提供直接編輯金額；若誤記，先作廢、再登記正確款項。作廢只修正帳本，不會實際轉帳，也不會自動退款。
