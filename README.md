## 已确认的核心方向

- iOS / iPhone 优先，繁體中文（香港）及英文；Local-First。
- Free 无限快速 AA、一个进行中活动且支出笔数无限；Pro 一次性买断。
- 一笔费用只使用一种主分账模式；基本真实商家退款和基础备份对 Free 开放。
